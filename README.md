##   Titre du projet   ##
TP_TicTacToe


##  Description ##
Projet Unity d'un jeu de Whack A Mole en VR. L'utilisateur prend le marteau et ensuite clique sur démarrer pour partir de jeu.
Quand je jeu part des cibles apparaissent aléatoirement sur la plateforme de jeu. Le joueur doit frapper les cibles avant un certain temps aussi non les cibles disparaissent.
Chaque fois que le joueur frappe une cible, elle se détruit et 10 points sont ajouter au compteur. à la fin du temps imparti, le jeu s'arrête et le joueur peux voir son score total et rejouer une partie.


## Version Unity et Packages ##
La version de Unity utilisé est la 6000.3.5f1
